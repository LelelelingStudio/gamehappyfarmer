头像素材库 — 玩家头像图片放在这个文件夹
==========================================

当前引擎读取范围：1.png ~ 180.png
（数量由 langdata/constants.js 里的 AVATAR_LIBRARY_COUNT 决定，
  以后想扩容到 200 张，只改那个数字即可，代码其它地方不用动）

要求建议：
  · 正方形（例如 256×256 或 512×512）
  · PNG 格式（带透明背景更好看）
  · 单张建议小于 200 KB，越小游戏启动越快
  · 文件名严格为 1.png、2.png … 180.png（区分大小写，不要用 01.png）

使用方式：
  进入游戏 → 右上角 👤 用户中心 → 「选择头像」→ 弹窗里选 emoji 或素材库图片。
  弹窗内部可上下滚动，右上角 × 关闭。

说明：
  · 素材库头像在存档里只记录文件名（例如 "7.png"），不写 base64，存档体积几乎不增加。
  · 如果某张图片不存在，对应格子显示灰色编号占位，不会出现裂图。
  · 图片加载失败只在本次会话内记忆；刷新页面或点弹窗里的「重新检测」会重新扫描。

★ 新增图片后请务必执行一次：
     node tools/build-manifest.js
   它会重新生成 assets/manifest.js（加载进度条用的资源清单）。
   否则新图片不会出现在进度条的“图片”阶段里（游戏里仍能选到，
   只是预加载不会把它算进去）。
